# NZ_agent_rules：エージェント向けカスタムルール集

本フォルダは、コーディングエージェントの行動を管理し、暴走（無断のコマンド実行や上書きなど）を防ぐための共通ルールを蓄積する場所です。

新しいプロジェクトを開始した際は、本フォルダのルールをエージェントに読み込ませるため、以下の手順を実行してください。

---

## 🚀 新しいプロジェクトでの利用手順

新しいプロジェクト（別のワークスペース）の開発を開始する前に、そのフォルダのルートで以下のコマンドを実行します。

```bash
# 1. カスタムルール用のフォルダを作成
mkdir -p .agents/rules

# 2. 本フォルダのすべてのルールを新しいプロジェクトにコピーして適用
cp /Users/shun_ishii/Projects/NZ_agent_rules/*.md .agents/rules/
```

これにより、新しく起動したエージェントがプロジェクト開始時にすべてのルールを自動ロードし、不要なリソースの消費や無断の破壊的変更を防ぐことができます。
